# TypeScript Code Style Guide

## Naming Conventions
- Functions: `camelCase`
- Classes: `PascalCase`
- Variables: `camelCase`
- Constants: `UPPER_CASE`

## Formatting
- 2-space indentation (Prettier)
- Max line length: 120 characters
- Strict mode enabled

## Type System
- Explicit types over `any`
- Prefer `readonly` for object properties
- Union types with pipe syntax

## Decorators
- Use sparingly; prefer plain classes with clear interfaces
