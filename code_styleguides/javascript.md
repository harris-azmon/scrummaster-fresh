# JavaScript Code Style Guide

## Naming Conventions
- Functions: `camelCase`
- Classes: `PascalCase`
- Variables: `camelCase`
- Constants: `UPPER_CASE`

## Formatting
- 2-space indentation
- Max line length: 100 characters
- Semicolons optional (ESLint configured)

## Imports
- ES modules syntax (`import/from`)
- Group by: external, internal, relative

## Type Handling
- Use TypeScript for type safety
- JSDoc for plain JavaScript type documentation
