# Workflow

## Default Process
- 80% test coverage requirement
- Commit after every task
- Git Notes for task summaries
- Automated review at end of each story

## Phase Completion Verification and Checkpointing Protocol
After each phase, verify completion by checking:
1. All required files exist in the story directory
2. Story registry (stories.md) is updated
3. Metadata is consistent across artifacts
4. Acceptance criteria are met
