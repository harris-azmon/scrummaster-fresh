# Product Guidelines

## Prose Style
- Technical/developer-focused tone
- Clear, concise language
- No marketing fluff

## Brand Messaging
- "Measure twice, code once"
- "Context as code"
- Feature-over-benefit framing

## Visual Identity
- Header hierarchy: h1 for epics, h2 for stories, h3 for ACIDs
- Mermaid diagrams for workflows
- Tables for ACID mapping

## Index-Driven Structure
- All guide files referenced from index.md
- Cross-links between related artifacts
